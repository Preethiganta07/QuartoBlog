🔍 Project Overview

Customer churn is one of the most critical metrics for any subscription-based or e-commerce business. Losing a customer costs 5–25× more than retaining one — yet most companies only notice churn after it’s too late.

In this project, we:

  • Simulate a realistic customer database using Python + SQLite
  • Run 8 SQL queries to analyze churn patterns
  • Visualize insights using Matplotlib & Seaborn
  • Derive actionable business recommendations

Tools Used: Python, SQLite3, Pandas, Matplotlib, Seaborn, NumPy

🗄️ Step 2: Create SQLite Database & Simulate Data

We simulate 2,000 customers with realistic attributes:

  • Demographics: Age, Gender, Location
  • Subscription: Plan type, Tenure, Monthly charges
  • Behaviour: Login frequency, Support tickets, Payment method
  • Target: Churned (1) or Active (0)
np.random.seed(42)
N = 2000

# ── Generate Customer Data ────────────────────────────────────────────────
customer_ids   = [f"CUST{str(i).zfill(5)}" for i in range(1, N+1)]
ages           = np.random.randint(18, 72, N)
genders        = np.random.choice(['Male', 'Female'], N)
locations      = np.random.choice(
    ['North', 'South', 'East', 'West', 'Central'],
    N, p=[0.25, 0.20, 0.25, 0.18, 0.12])
plans          = np.random.choice(
    ['Basic', 'Standard', 'Premium'],
    N, p=[0.40, 0.35, 0.25])
tenure_months  = np.random.randint(1, 73, N)
monthly_charge = np.where(plans == 'Basic',
                    np.random.uniform(10, 30, N),
                    np.where(plans == 'Standard',
                        np.random.uniform(30, 60, N),
                        np.random.uniform(60, 100, N)))
monthly_charge = np.round(monthly_charge, 2)
login_freq     = np.random.randint(0, 31, N)
support_tickets= np.random.randint(0, 11, N)
payment_methods= np.random.choice(
    ['Credit Card', 'Debit Card', 'Net Banking', 'UPI', 'Wallet'],
    N, p=[0.30, 0.25, 0.20, 0.15, 0.10])

# ── Churn Logic (realistic rules) ────────────────────────────────────────
churn_prob = (
    0.35 * (plans == 'Basic').astype(int) +
    0.15 * (plans == 'Standard').astype(int) +
    0.05 * (plans == 'Premium').astype(int) +
    0.25 * (tenure_months < 6).astype(int) +
    0.10 * (support_tickets > 5).astype(int) +
    0.15 * (login_freq < 5).astype(int) +
    np.random.uniform(0, 0.1, N)
)
churn_prob = np.clip(churn_prob, 0, 1)
churned    = (np.random.uniform(0, 1, N) < churn_prob).astype(int)

# ── Build DataFrame ───────────────────────────────────────────────────────
df = pd.DataFrame({
    'customer_id'     : customer_ids,
    'age'             : ages,
    'gender'          : genders,
    'location'        : locations,
    'plan'            : plans,
    'tenure_months'   : tenure_months,
    'monthly_charge'  : monthly_charge,
    'login_frequency' : login_freq,
    'support_tickets' : support_tickets,
    'payment_method'  : payment_methods,
    'churned'         : churned
})

# ── Load into SQLite ──────────────────────────────────────────────────────
conn = sqlite3.connect(':memory:')
df.to_sql('customers', conn, index=False, if_exists='replace')

print(f"✅ Database created with {N} customers")
print(f"📊 Churn Rate: {churned.mean()*100:.1f}%")
print(f"\n🗂️  Table Schema:")
print(df.dtypes.to_string())

🔍 Step 4: SQL Queries — Churn Analysis

We run 8 key SQL queries to understand churn patterns.

Query 1 — Overall Churn Rate

q1 = pd.read_sql("""
    SELECT
        COUNT(*) AS total_customers,
        SUM(churned) AS churned_customers,
        ROUND(SUM(churned) * 100.0 / COUNT(*), 2) AS churn_rate_pct,
        COUNT(*) - SUM(churned) AS active_customers
    FROM customers
""", conn)

Query 2 — Churn Rate by Subscription Plan

q2 = pd.read_sql("""
    SELECT
        plan,
        COUNT(*) AS total,
        SUM(churned) AS churned,
        ROUND(SUM(churned) * 100.0 / COUNT(*), 2) AS churn_rate_pct,
        ROUND(AVG(monthly_charge), 2) AS avg_monthly_charge
    FROM customers
    GROUP BY plan
    ORDER BY churn_rate_pct DESC
""", conn)

Query 3 — Churn by Tenure Group

q3 = pd.read_sql("""
    SELECT
        CASE
            WHEN tenure_months <= 6  THEN '0-6 months'
            WHEN tenure_months <= 12 THEN '7-12 months'
            WHEN tenure_months <= 24 THEN '13-24 months'
            WHEN tenure_months <= 48 THEN '25-48 months'
            ELSE '49+ months'
        END AS tenure_group,
        COUNT(*) AS total,
        SUM(churned) AS churned,
        ROUND(SUM(churned) * 100.0 / COUNT(*), 2) AS churn_rate_pct
    FROM customers
    GROUP BY tenure_group
    ORDER BY churn_rate_pct DESC
""", conn)

Query 5 — High Risk Customers (Churn Score)

q5 = pd.read_sql("""
    SELECT
        customer_id, plan, tenure_months,
        monthly_charge, support_tickets, login_frequency,
        ROUND(
            (support_tickets * 10) +
            ((6 - MIN(login_frequency, 5)) * 8) +
            (CASE WHEN tenure_months < 6 THEN 20 ELSE 0 END) +
            (CASE WHEN plan = 'Basic' THEN 15 ELSE 0 END)
        , 0) AS risk_score
    FROM customers
    WHERE churned = 0
    ORDER BY risk_score DESC
    LIMIT 10
""", conn)

Query 6 — Churn by Support Tickets

q6 = pd.read_sql("""
    SELECT
        CASE
            WHEN support_tickets = 0 THEN 'No tickets'
            WHEN support_tickets <= 2 THEN '1-2 tickets'
            WHEN support_tickets <= 5 THEN '3-5 tickets'
            ELSE '6+ tickets'
        END AS ticket_group,
        COUNT(*) AS total,
        SUM(churned) AS churned,
        ROUND(SUM(churned) * 100.0 / COUNT(*), 2) AS churn_rate_pct
    FROM customers
    GROUP BY ticket_group
    ORDER BY churn_rate_pct DESC

Query 7 — Revenue Lost to Churn

q7 = pd.read_sql("""
    SELECT
        plan,
        SUM(CASE WHEN churned=1 THEN monthly_charge ELSE 0 END) AS monthly_revenue_lost,
        ROUND(SUM(CASE WHEN churned=1 THEN monthly_charge ELSE 0 END) * 12, 2) AS annual_revenue_lost,
        SUM(CASE WHEN churned=0 THEN monthly_charge ELSE 0 END) AS monthly_revenue_retained
    FROM customers
    GROUP BY plan
    ORDER BY annual_revenue_lost DESC
""", conn)
total_lost = q7['annual_revenue_lost'].sum()

📝 Step 6: Key Insights & Business Recommendations

🔵 Key Findings

# Finding Impact
1 Basic plan has highest churn (~45%) Customers feel undervalued at low price point
2 New customers (0–6 months) churn most Onboarding experience is critical
3 6+ support tickets = highest churn Poor service experience drives churn
4 Low login frequency predicts churn Disengaged users leave silently
5 Annual revenue lost to churn is significant Retention > Acquisition in ROI

✅ Business Recommendations

  1. Improve Basic plan onboarding — Add welcome emails, tutorials, check-ins in first 90 days
  2. Create Early Warning System — Flag customers with low logins + high support tickets
  3. Offer retention discounts — Target at-risk customers before they cancel
  4. Fix top support pain points — Reduce tickets by improving product/documentation
  5. Loyalty rewards for long-tenure customers — Reward customers who stay 12+ months
